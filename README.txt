LÄKEMEDELSTRÄNING – PWA VERSION 5

Publicera via GitHub Pages:
1. Skapa ett offentligt repository på github.com (t.ex. lakemedelstraning).
2. Ladda upp INNEHÅLLET i denna ZIP till repositoryts rot (inte ZIP-filen).
3. Öppna Settings > Pages > Build and deployment > Deploy from a branch.
4. Välj main och /(root), spara.
5. Öppna adressen som GitHub Pages visar (https://ANVANDARE.github.io/lakemedelstraning/).
6. På Android: öppna i Chrome och välj Installera app/Lägg till på startskärmen. På iPhone: Safari > Dela > Lägg till på hemskärmen.

Offline: Öppna appen en gång med internet efter publicering. Den cachas sedan lokalt. Vid uppdatering kan webbläsaren behöva laddas om.

VIKTIGT: Endast utbildning. Läkemedelsdata och patientfall måste granskas medicinskt och spridningsrättigheter kontrolleras före offentlig publicering. Inga kliniska ordinationer ska baseras på appen.
